# GRASS GIS Scripts — Image Segmentation and Classification of Landsat over the Sudd Wetlands

GRASS GIS scripts, clustering results, computed kappa parameters and error matrices used in the peer-reviewed article by Polina Lemenkova.

**Paper:** Image Segmentation of the Sudd Wetlands in South Sudan for Environmental Analytics by GRASS GIS Scripts
**Published in:** *Analytics* **2023**, *2*(3), 745–780
**DOI:** https://doi.org/10.3390/analytics2030040

## Contents
Scripts for `i.segment` (region-growing image segmentation), `i.cluster` / `i.maxlik` (clustering and maximum-likelihood classification), `r.kappa` (accuracy assessment / error matrices), and NDVI computation, applied to a 2015–2023 time series of Landsat 8-9 OLI/TIRS scenes.

## Citation
